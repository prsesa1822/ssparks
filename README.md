# Sarah Sparks Technical Portfolio

Static GitHub Pages portfolio focused on AI operations, workflow automation, CRM data quality, local AI infrastructure, RAG, and customer operations.

## Project status

- **Inbox Warden — Case study:** human-in-the-loop Gmail triage with n8n, the OpenAI Responses API, structured JSON, six labels, and a Review fallback.
- **Resume Crypt — Live:** evidence-first résumé scanning, tailoring, cover-letter generation, and integrity review.
- **Local AI Infrastructure — Self-hosted:** Docker, Ollama, Open WebUI, local RAG collections, and Tasker-to-Telegram notification automation.
- **CRM & Customer Operations — Case study:** self-initiated 883-record HubSpot audit, 811 missing email addresses, and a proposed—not adopted—30-60-90 remediation plan.
- **Death Care in Data — Supporting project:** sourced descriptive comparison of projected 2025 U.S. cremation and burial rates.
- **Dragon Hoard — Earlier project:** Claude API career-document and professional-communication tool. The previous public link is withheld pending an access and deployment review.
