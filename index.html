Featured Project

Inbox Warden: safe AI triage for the modern inbox.

An n8n workflow that reads incoming Gmail messages, uses the OpenAI Responses API for structured classification, and routes each message into a useful category. Uncertain email stays visible for human judgment; high-risk automation is deliberately constrained.

What it does

Classifies full message context and applies one of six Gmail labels: Important, LinkedIn, Bills & Purchases, Phantom, Review, or Trash.

Why it matters

Protects attention without pretending AI should make every decision. Important career email remains visible, background content moves aside, and ambiguity goes to Review.

What it proves

I can combine prompt engineering, structured outputs, API integration, deterministic routing, and human-centered safeguards into a working operational system.

Featured Project

Phantom Inbox: intelligent email triage with Claude and n8n.

An automated Gmail classification and routing pipeline that converts incoming emails into structured decisions. The project demonstrates AI workflow design, API orchestration, OAuth setup, JSON handling, deterministic routing, and production-minded deployment judgment.

What it does

Extracts subject, sender, body, and message context, sends the data to Claude, then routes each message based on category, confidence, action, and reasoning.

Why it matters

It turns a 15,000+ message backlog into an operational workflow that reduces inbox noise without depending on constant manual sorting.

What it proves

I can identify a real bottleneck, design a system, work across APIs, debug platform issues, and know when to change deployment paths.
