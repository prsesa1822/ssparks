Inbox Warden: AI triage that protects human attention.

An AI-powered Gmail triage system built with n8n, the OpenAI Responses API, and the Gmail API. Inbox Warden organizes incoming messages without automatically replying or taking high-risk action when the right decision is unclear.

The production workflow reads a new message, extracts the relevant context, sends it to OpenAI for structured classification, parses the JSON response, and applies the appropriate Gmail label. The screenshot contains no email content, credentials, or private inbox data.

Why I Built This

Modern inboxes demand context, but context should not erase human judgment.

Newsletters, promotions, financial alerts, applications, recruiter messages, LinkedIn notifications, and spam all compete for attention. Traditional filters miss context; fully autonomous systems can make costly mistakes by hiding or deleting the wrong message.

Protect attention

Move background information out of the primary decision queue so urgent, career-related communication is easier to see.

Use context

Classify the meaning of a message—not just a keyword or sender—using a focused prompt and structured response.

Keep humans in control

Leave uncertain messages in the Inbox for review instead of forcing a risky classification.

Features

From incoming message to safe, structured action.

Automatic monitoring

Watches for new Gmail messages and retrieves the full content needed for classification.

Context-aware AI

Uses the OpenAI Responses API to distinguish career mail, financial activity, notifications, background content, and junk.

Structured JSON

Parses predictable machine-readable output before any routing decision reaches Gmail.

Automatic labels

Applies clear Gmail labels so each category has a useful place and purpose.

Career prioritization

Keeps recruiter outreach, interviews, assessments, offers, and time-sensitive requests prominent.

Conservative fallback

Avoids destructive action when confidence is low and sends ambiguous messages to Review.

System Design

AI reasoning constrained by deterministic routing.

The model recommends a category. n8n validates and routes the structured result. Gmail performs only the pre-approved action associated with that route.

1

New email

A Gmail trigger starts the workflow when a message arrives.

2

Read full message

The Gmail API retrieves the content and headers needed to understand the message.

3

Extract metadata

JavaScript prepares sender, subject, body, and other relevant context for a clean API request.

4

OpenAI classification

The Responses API evaluates the email against explicit category and safety instructions.

5

Parse JSON

The workflow converts the model output into validated fields the router can use.

6

Decision router

n8n applies the matching Gmail label—or defaults to Review when the classification is uncertain.

Classification Categories

Six routes, each designed around a real attention decision.

⭐

Important

High-priority career communication: recruiter outreach, hiring manager messages, interview invitations, technical assessments, offer letters, and time-sensitive application requests.

💼

LinkedIn

LinkedIn-generated activity such as job alerts, application confirmations, connection updates, profile analytics, and post engagement.

💳

Bills & Purchases

Bank alerts, declined card notices, statements, receipts, shipping updates, order confirmations, and payment reminders.

👻

Phantom

The background inbox for useful but non-urgent information: newsletters, promotions, coupons, software updates, book deals, and marketing email.

👀

Review

The safety net. Ambiguous messages intentionally remain in the Inbox for human judgment instead of being forced into another category.

🗑️

Trash

Reserved for high-confidence phishing, malware, scam campaigns, fake invoices, and mass spam. When uncertain, Inbox Warden never chooses Trash.

Design Philosophy

Fail safely.

Inbox Warden is designed for accuracy and oversight, not maximum automation. The safest useful action is more valuable than the most aggressive one.

01

Important email should never disappear.

Career communication stays visible and easy to act on.

02

AI should admit uncertainty.

Review is an intentional outcome, not an error state.

03

Humans make the final call.

Low-confidence decisions stay recoverable and visible.

Lessons Learned

Production AI is a system of judgment, rules, and feedback.

The goal is not to let AI make every decision. Reliable outcomes come from combining deterministic rules, human judgment, and AI reasoning—then refining the system through structured outputs, safe failure, and iterative prompt testing.

Reliability beats autonomy

A workflow that safely escalates uncertainty is more useful than one that confidently automates every edge case.

Structure enables trust

Explicit categories and parseable JSON turn a flexible model response into an auditable operational decision.
