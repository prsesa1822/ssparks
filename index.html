Featured Project

Inbox Warden: safe AI triage for a crowded inbox.

The workflow retrieves complete Gmail messages, extracts metadata, asks the OpenAI Responses API for structured JSON, and uses deterministic n8n routing to apply one of six labels. Review remains in the inbox for human judgment; Trash is reserved for high-confidence junk.

Context-aware classification

Important, LinkedIn, Bills & Purchases, Phantom, Review, and Trash provide useful separation without automated replies.

Human-in-the-loop design

Low-confidence messages are intentionally left visible rather than forced into a risky category.

Operational proof

The project combines prompt design, structured outputs, APIs, OAuth, JavaScript parsing, and routing safeguards.
